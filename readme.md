Overview
This is a machine learning project aimed at recommending books to users based on various factors such as genres, authors, and user preferences. The system uses a recommendation algorithm to suggest books from a dataset.
Features
Content-based filtering: Recommends books similar to ones that the user has liked.
Collaborative filtering: Uses user interactions to recommend books based on similar user preferences.
Tech Stack
Frontend: html css for the UI
Backend: Django (Python) for managing user recommendations and database interactions
Machine Learning: Implemented in Python using algorithms like KNN, cosine similarity, or other suitable recommendation algorithms
Prerequisites
Python 3.x
Django
Html css
